三、部署与启动
3.1 导入数据库
启动 MySQL 8，使用命令行或图形工具导入全量脚本。脚本内已包含建库、建表与演示数据，字符集为 utf8mb4：
mysql -uroot -p < &quot;01_可运行程序\数据库\art_training_full_2026-10-20.sql&quot;

-- 验证
mysql -uroot -p -e &quot;USE art_training; SHOW TABLES;&quot;

默认连接配置为 localhost:3306、用户 root、空密码。若本机 MySQL 设置了密码，请修改 backend/src/main/resources/application-dev.yml 中的 password 字段。
3.2 启动后端（8080）
进入 01_可运行程序\backend，二选一启动：
REM 方式一：直接运行已构建的 jar（推荐，无需 Maven）
java -jar target\art-training-backend-0.0.1-SNAPSHOT.jar

REM 方式二：从源码启动
mvn spring-boot:run

启动成功后控制台出现 Tomcat started on port 8080，并输出数据库连接与初始化日志，即表示后端就绪；随后可继续启动前端，通过登录页验证接口是否连通。
3.3 启动 Python 评分服务（8000）
首次运行需创建独立环境并安装依赖，之后每次只需启动服务：
cd 01_可运行程序\dance
conda create -n dance python=3.10 -y
conda activate dance
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

REM 启动（Windows）
set DANCE_API_HOST=127.0.0.1
python api_server.py

REM 健康检查
curl http://127.0.0.1:8000/api/health

3.4 启动前端（5173）
进入 01_可运行程序\frontend，依赖已随包提供：
cd 01_可运行程序\frontend
npm run dev

REM 若需重新安装依赖
npm install

浏览器访问 http://localhost:5173 进入系统。若 5173 被占用，Vite 会自动顺延端口，请以控制台输出为准。

五、功能使用指引
5.1 管理端
1. 登录后进入工作台，可查看课程、学员、教师与营收概览。
2. “课程与班级—排课管理”中新增排课，系统自动检测教师、教室、班级三重冲突并拦截。
3. “报名与财务”中为学员报名并生成订单，缴费后报名状态联动更新。
4. “考勤管理”按班级点名，考勤记录与课消统计联动。
5. “运营统计”按时间区间查看报名、收入、续课率等指标。
6. “知识库”支持文档入库、检索、自动归集与备份；“AI 模型管理”维护模型与密钥。
7. “智能体”支持自然语言创建课程、发起调课申请与审批，敏感操作需二次确认。
5.2 教师端与 AI 评分
1. 教师登录后进入“作业管理”，选择班级与课程布置作业，可指定参考视频。
2. 学员提交练习视频后，教师在作业列表点击“AI 评分”，系统依次执行预处理、姿态提取、DTW 对齐、评分与可视化。
3. 评分过程中对话框显示阶段进度与百分比；首次评分约需数十秒至数分钟，取决于视频时长与机器性能。
4. 完成后进入“AI 评分报告”：左栏为总分与 6 部位、3 维度得分；中栏为五路视频与实时节奏曲线；右栏为偏差热力图、最差关键帧与 AI 语义点评。
5. 点击“生成 AI 点评”可按需刷新语义分析；未配置模型密钥时，量化评分与图表仍可正常使用。
6. 教师可基于报告给出文字评语并发布成绩。
5.3 学员端
1. 学员使用学号登录，首页查看课表、待交作业与通知。
2. “我的作业”中上传练习视频（支持大文件，前端超时 10 分钟），提交后可查看评分状态。
3. 评分完成后打开报告，可查看与教师端一致的分部位得分、五路视频、节奏曲线与 AI 教练建议。
4. “敦煌展馆”中可选择八类参考动作，播放骨架动画、缩放旋转并查看标志性姿态。
5. 右下角桌宠可进行多轮问答，回答优先基于知识库内容。

八、常见问题
现象
可能原因
处理方法
8080 端口被占用
已有后端进程或其它服务
执行 scripts\stop-system.bat，或 taskkill 对应 PID
数据库连接失败
MySQL 未启动、库未导入、密码不一致
启动 MySQL，确认 art_training 存在，修改 application-dev.yml
评分一直“评分中”后失败
8000 未启动或后端仍指向远程地址
启动 python api_server.py，确认 dance.api.url 为 127.0.0.1:8000
音轨抽取失败
FFmpeg 未安装或不在 PATH
安装 FFmpeg 并配置 PATH，命令行执行 ffmpeg -version 验证
姿态提取报错
MediaPipe 版本不匹配
固定安装 mediapipe==0.10.14
大视频上传失败
请求超时或超过大小限制
确认上传上限 1024MB、前端超时 600 秒；必要时压缩后上传
视频播放卡顿或回退
浏览器缓存旧分段
刷新页面；资源 URL 已加时间戳，仍异常时清理浏览器缓存
AI 点评为空
第三方模型密钥未配置或网络不通
在管理端填写密钥；量化评分与图表不受影响
npm run dev 失败
Node 版本过低
升级至 Node 18 及以上后重试
